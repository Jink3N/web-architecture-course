🟢 Esercizio 1 — Delay Promessa

Consegna

Scrivi una funzione ritarda(ms) che restituisce una Promise risolta dopo ms millisecondi. Usa setTimeout.

Soluzione guida

function ritarda(ms) {
  return new Promise(resolve => {
    setTimeout(() => resolve(`Passati ${ms} ms`), ms);
  });
}

ritarda(2000).then(console.log);
// Output dopo 2s: "Passati 2000 ms"

Variante

Gestisci il caso in cui ms non sia un numero: rigetta la Promise con un errore descrittivo.

Scenario reale

Le notifiche push di un'app mobile spesso hanno bisogno di un leggero ritardo per evitare spam. La funzione ritarda può essere usata per schedulare l'invio di messaggi "Promemoria pagamento" cinque minuti dopo un acquisto.

🟡 Esercizio 2 — Async/Await e gestione errori

Consegna

Simula il download di dati da un'API. La funzione scaricaDati() deve restituire un oggetto dopo 1 secondo. Usa async/await e gestisci gli errori con try/catch.

Soluzione guida

function fintaApi() {
  return new Promise((resolve, reject) => {
    const ok = Math.random() > 0.3; // 70% successo
    setTimeout(() => {
      ok ? resolve({ user: "Ada", ruolo: "admin" })
         : reject(new Error("Server occupato"));
    }, 1000);
  });
}

async function scaricaDati() {
  try {
    const risposta = await fintaApi();
    console.log("Dati ricevuti", risposta);
  } catch (errore) {
    console.error("Riprova più tardi", errore.message);
  }
}

scaricaDati();

Variante

Aggiungi un tentativo di retry: se fallisce, attendi 500ms e riprova una seconda volta.

Scenario reale

Un CRM che sincronizza i contatti con un servizio esterno (es. piattaforma newsletter) deve gestire momentanei picchi di traffico. Con try/catch e un retry programmato evitiamo di segnare l'operazione come fallita al primo errore di rete.

🔵 Esercizio 3 — Promise.all

Consegna

Avvia tre chiamate asincrone in parallelo (es. tre ritardi diversi) e stampa i risultati quando tutte sono completate.

Soluzione guida

const download1 = ritarda(500).then(() => "📄 Documento");
const download2 = ritarda(800).then(() => "🎧 Audio");
const download3 = ritarda(300).then(() => "🖼️ Immagine");

Promise.all([download1, download2, download3])
  .then(risultati => console.log("Completati:", risultati))
  .catch(console.error);

Variante

Prova Promise.allSettled() per ottenere il risultato anche se alcune Promise falliscono.

Scenario reale

Una dashboard marketing carica in parallelo i report di Google Ads, Meta Ads e TikTok. Solo quando tutte le campagne sono state scaricate mostriamo il grafico comparativo. Con Promise.all riduciamo i tempi di attesa.

🟠 Esercizio 4 — API Reale: Convertitore Valute

Consegna

Crea un convertitore di valute che utilizza l'API ExchangeRate-API (gratuita, senza registrazione). La funzione deve:

  • Prendere due parametri: importo e valutaDestinazione (es. "USD", "JPY", "GBP")
  • Convertire da EUR alla valuta scelta
  • Gestire errori di rete e valute non supportate
  • Mostrare la data dell'ultimo aggiornamento dei tassi

📚 Cos'è fetch() e come funziona

fetch() è la funzione moderna di JavaScript per fare richieste HTTP. Sostituisce il vecchio XMLHttpRequest ed è più semplice da usare.

Caratteristiche principali:

  • Promise-based: Restituisce una Promise, perfetta con async/await
  • Nativo del browser: Non serve installare librerie esterne
  • Flessibile: Supporta GET, POST, PUT, DELETE e altri metodi HTTP
  • Moderno: Gestione automatica di JSON, blob, text, etc.

Sintassi base:

// Richiesta GET semplice
const response = await fetch('https://api.example.com/data');
const data = await response.json();

// Con gestione errori
if (!response.ok) {
  throw new Error(`HTTP ${response.status}: ${response.statusText}`);
}

Cosa fa fetch() internamente:

  1. Crea la richiesta HTTP verso l'URL specificato
  2. Aspetta la risposta del server (può richiedere tempo)
  3. Restituisce un oggetto Response con headers, status, etc.
  4. Il contenuto va estratto con .json(), .text(), .blob(), etc.

🗺️ Guida passo-passo: La tua prima chiamata API

Se non hai mai lavorato con API reali, segui questi passaggi nell'ordine esatto:

Passo 1: Testa l'URL nel browser

Apri https://api.exchangerate-api.com/v4/latest/EUR in una nuova scheda. Vedrai i dati JSON grezzi - questo conferma che l'API funziona.

Passo 2: Chiamata base senza gestione errori

async function primaChiamata() {
  const response = await fetch('https://api.exchangerate-api.com/v4/latest/EUR');
  const dati = await response.json();
  console.log(dati); // Esplora la struttura dei dati
}

Passo 3: Estrai un valore specifico

async function estraiTasso() {
  const response = await fetch('https://api.exchangerate-api.com/v4/latest/EUR');
  const dati = await response.json();
  console.log('Tasso EUR -> USD:', dati.rates.USD);
  console.log('Data aggiornamento:', dati.date);
}

Passo 4: Aggiungi gestione errori

async function chiamataSicura() {
  try {
    const response = await fetch('https://api.exchangerate-api.com/v4/latest/EUR');
    
    if (!response.ok) {
      throw new Error(`Errore HTTP: ${response.status}`);
    }
    
    const dati = await response.json();
    console.log('Successo!', dati.rates.USD);
  } catch (errore) {
    console.error('Qualcosa è andato storto:', errore.message);
  }
}

Passo 5: Crea la funzione finale

Solo ora sei pronto per implementare la soluzione completa qui sotto! 👇

Soluzione guida

async function convertitoreValute(importo, valutaDestinazione) {
  const apiUrl = `https://api.exchangerate-api.com/v4/latest/EUR`;
  
  try {
    console.log(`🔄 Recupero tassi di cambio...`);
    
    const response = await fetch(apiUrl);
    
    if (!response.ok) {
      throw new Error(`HTTP Error: ${response.status}`);
    }
    
    const dati = await response.json();
    
    // Controlla se la valuta esiste
    if (!dati.rates[valutaDestinazione]) {
      throw new Error(`Valuta ${valutaDestinazione} non supportata`);
    }
    
    const tassoCambio = dati.rates[valutaDestinazione];
    const importoConvertito = (importo * tassoCambio).toFixed(2);
    
    const risultato = {
      importoOriginale: `${importo} EUR`,
      importoConvertito: `${importoConvertito} ${valutaDestinazione}`,
      tassoCambio: tassoCambio,
      dataAggiornamento: dati.date
    };
    
    console.log('💰 Conversione completata:', risultato);
    return risultato;
    
  } catch (errore) {
    console.error('❌ Errore nella conversione:', errore.message);
    throw errore;
  }
}

// Esempio di utilizzo
async function testConversioni() {
  try {
    await convertitoreValute(100, 'USD');
    await convertitoreValute(50, 'JPY');
    await convertitoreValute(25, 'GBP');
  } catch (errore) {
    console.log('Operazione fallita, riprova più tardi');
  }
}

testConversioni();

Variante avanzata

Aggiungi un sistema di cache: se hai già fatto una richiesta negli ultimi 10 minuti, usa i dati salvati in memoria invece di rifare la chiamata API. Implementa anche la conversione bidirezionale (da qualsiasi valuta a qualsiasi altra).

Note tecniche

  • CORS: Questa API supporta le richieste dal browser, quindi puoi testarla anche su CodePen/JSFiddle
  • Rate limits: 1500 richieste gratuite al mese senza registrazione
  • Valute supportate: Oltre 160 valute mondiali (USD, JPY, GBP, CHF, CAD, AUD, etc.)
  • Formato date: L'API restituisce date nel formato YYYY-MM-DD

🔍 Debugging APIs: Cosa fare quando qualcosa non va

Errori comuni e soluzioni:

❌ "TypeError: Failed to fetch"
Soluzione: Controlla la connessione internet e l'URL dell'API
❌ "Unexpected token in JSON"
Soluzione: L'API ha restituito HTML invece di JSON (probabilmente errore 404/500)
❌ "Cannot read property 'USD' of undefined"
Soluzione: Controlla la struttura del JSON prima di accedere alle proprietà

Tecniche di debugging:

// 1. Logga sempre la response prima di processarla
console.log('Response status:', response.status);
console.log('Response headers:', response.headers);

// 2. Esplora la struttura dei dati
console.log('Struttura completa:', JSON.stringify(dati, null, 2));

// 3. Controlla se una proprietà esiste prima di usarla
if (dati.rates && dati.rates.USD) {
  console.log('USD rate:', dati.rates.USD);
} else {
  console.error('USD rate non trovato!');
}

Scenario reale

Un e-commerce internazionale mostra i prezzi in valuta locale. Ogni volta che un cliente cambia paese, il sistema deve convertire tutti i prezzi. Con questa API puoi costruire il modulo che aggiorna automaticamente carrello e checkout, migliorando l'esperienza utente per clienti da USA, Giappone, Regno Unito, etc.

🧭 Strategie di debug

🪝 Usa console.time

Misura quanto durano le operazioni asincrone per capire dove ottimizzare.

📜 Log descrittivi

Aggiungi messaggi come "In attesa di risposta..." per seguire il flusso.

🐛 Breakpoint

Nei playground puoi usare gli strumenti di debug del browser per fermare l'esecuzione.

🧪 Test a casi limite

Prova cosa succede se una Promise impiega più tempo o se rigetta subito.
