📦 Node.js: Oggetti & CRUD

Conosci gli oggetti globali più usati in Node.js, esplora il modulo fs per lavorare con i file e prepara la tua prima libreria CRUD senza database.

🧭 Orientarsi nel runtime

Oggetti globali principali

  • process: informazioni sull'applicazione in esecuzione (variabili d'ambiente, PID, eventi).
  • __dirname: percorso assoluto della cartella corrente.
  • __filename: percorso completo del file corrente.
  • module e exports: gestiscono come condividere funzioni e oggetti tra file.
  • global: oggetto radice (simile a window nel browser), da usare con moderazione.

Termine complesso: CommonJS

È il sistema di moduli storico di Node.js. Permette di importare/esportare codice con require() e module.exports. Oggi Node supporta anche gli ES Modules (import/export), ma CommonJS è ancora molto diffuso.

🗂️ Il modulo fs (File System)

Il modulo fs permette di leggere, creare, aggiornare ed eliminare file. Esistono versioni sincrone e asincrone. Preferiamo l'uso asincrono per non bloccare l'event loop.

const fs = require("fs/promises");

async function leggiFile(percorso) {
  try {
    const contenuto = await fs.readFile(percorso, "utf-8");
    console.log(contenuto);
  } catch (errore) {
    console.error("Impossibile leggere il file", errore.message);
  }
}

Metodi utili di fs/promises

  • readFile: legge un file e restituisce il contenuto.
  • writeFile: crea o sovrascrive un file.
  • appendFile: aggiunge dati alla fine di un file.
  • mkdir / rm: crea o rimuove directory e file.

📚 Creiamo una mini libreria

Obiettivo: costruire una libreria che gestisce un archivio di libri salvato in un file JSON. Implementeremo le operazioni CRUD (Create, Read, Update, Delete) senza database.

1. Struttura del progetto

Crea una cartella library con due file: books.json (inizialmente []) e library.js.

2. Funzioni CRUD

  • Create: aggiungi un libro con ID univoco.
  • Read: restituisci l'elenco completo o un singolo libro.
  • Update: aggiorna titolo/autore di un libro esistente.
  • Delete: rimuovi un libro per ID.

3. Salvataggio su file

Usa fs.readFile e fs.writeFile per sincronizzare l'array in memoria con il file books.json.

🛠️ Esempio di implementazione

const fs = require("fs/promises");
const path = require("path");
const { randomUUID } = require("crypto");

const PATH = path.resolve(__dirname, "books.json");

async function leggiCatalogo() {
    const dati = await fs.readFile(PATH, "utf-8");
    return JSON.parse(dati);
}

async function salvaCatalogo(catalogo) {
    await fs.writeFile(PATH, JSON.stringify(catalogo, null, 2));
}

async function aggiungiLibro(libro) {
    const catalogo = await leggiCatalogo();
    const nuovoLibro = { id: randomUUID(), ...libro };
    catalogo.push(nuovoLibro);
    await salvaCatalogo(catalogo);
    return nuovoLibro;
}

Nota sulle versioni Node

randomUUID() è disponibile da Node.js 14.17. In versioni precedenti puoi installare il pacchetto uuid con npm install uuid e usare const { v4: uuid } = require("uuid");.

🧪 Attività per la classe

  1. Implementa tutte le funzioni CRUD.
  2. Aggiungi un comando CLI (node library.js add "Titolo" "Autore").
  3. Gestisci gli errori: libro non trovato, file non accessibile.
  4. Bonus: ordina i libri per titolo prima di salvarli.

📚 Glossario

CRUD
Acronimo per Create, Read, Update, Delete: operazioni fondamentali sui dati.
JSON
Formato testuale per rappresentare oggetti JavaScript. Facile da leggere e scambiare.
I/O
Input/Output: lettura e scrittura su risorse esterne (file, rete).
CLI
Command Line Interface: modalità per usare il programma da terminale.

📦 Caso reale: inventory per libreria indipendente

Una piccola libreria di quartiere usa Node.js su un Raspberry Pi per tenere traccia dei libri in magazzino. Il personale può aggiungere rapidamente nuovi arrivi o segnare i titoli venduti senza un database complesso.

Workflow operativo

  • Alla consegna dei libri il commesso esegue node library.js add "Il nome della rosa" "Eco".
  • Ogni sera il comando node library.js list --format=table stampa l'inventario per controllare gli scaffali.
  • Quando un titolo finisce, node library.js remove --id <uuid> aggiorna il catalogo e libera spazio a magazzino.

Benefici immediati

  • Niente installazioni complesse: basta Node.js e due file.
  • I dati sono in formato JSON, facile da condividere con un gestionale più avanzato in futuro.
  • Il codice è estendibile: in un secondo momento si può esporre un'API REST usando Express.
