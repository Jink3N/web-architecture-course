🌐 Oggetti Globali in Node.js

Strumenti essenziali disponibili ovunque: process, Buffer, __dirname e molto altro

🔧 L'oggetto process

Rappresenta il processo Node.js corrente. Docs: Node.js Process 

// Informazioni ambiente
console.log(process.version);        // v18.16.0
console.log(process.platform);       // linux, darwin, win32
console.log(process.arch);           // x64, arm64
console.log(process.pid);            // ID processo

// Variabili d'ambiente
console.log(process.env.NODE_ENV);   // development, production
console.log(process.env.PORT);       // 3000

// Argomenti linea comando
// node app.js --port 3000 -v
console.log(process.argv);
// ['node', '/path/to/app.js', '--port', '3000', '-v']

// Directory e file correnti
console.log(process.cwd());          // Working directory
console.log(__dirname);              // Directory del file
console.log(__filename);             // Path completo file

// Uscita dal processo
process.exit(0);   // Successo
process.exit(1);   // Errore

// Eventi processo
process.on('exit', (code) => {
    console.log('Uscita con codice:', code);
});

process.on('uncaughtException', (err) => {
    console.error('Errore non gestito:', err);
    process.exit(1);
});

💾 Buffer: gestire dati binari

Buffer gestisce dati binari (immagini, video, file). Docs: Node.js Buffer 

// Creare Buffer
const buf1 = Buffer.from('Hello World');
const buf2 = Buffer.from([72, 101, 108, 108, 111]);
const buf3 = Buffer.alloc(10);  // 10 bytes vuoti
const buf4 = Buffer.allocUnsafe(10);  // Non inizializzato (veloce)

// Leggere e scrivere
buf1.toString();                  // 'Hello World'
buf1.toString('hex');             // '48656c6c6f20576f726c64'
buf1.toString('base64');          // 'SGVsbG8gV29ybGQ='

// Manipolazione
console.log(buf1.length);         // 11
console.log(buf1[0]);             // 72 (codice ASCII 'H')
buf1[0] = 74;                     // Modifica in 'J'

// Concatenazione
const buf5 = Buffer.concat([buf1, buf2]);

// Confronto
buf1.equals(buf2);                // true se identici
Buffer.compare(buf1, buf2);       // -1, 0, 1

⏱️ Timer globali

// setTimeout: esegue dopo N millisecondi
const timeout = setTimeout(() => {
    console.log('Eseguito dopo 2 secondi');
}, 2000);
clearTimeout(timeout);  // Annulla

// setInterval: esegue ogni N millisecondi
const interval = setInterval(() => {
    console.log('Ogni secondo');
}, 1000);
clearInterval(interval);  // Ferma

// setImmediate: esegue nel prossimo ciclo event loop
setImmediate(() => {
    console.log('Immediato');
});

// process.nextTick: priorità massima (prima di I/O)
process.nextTick(() => {
    console.log('Next tick');
});

🌐 URL e URLSearchParams

API standard per manipolare URL. Docs: Node.js URL 

const url = new URL('https://api.example.com/users?page=2&limit=10');

console.log(url.protocol);   // 'https:'
console.log(url.hostname);   // 'api.example.com'
console.log(url.pathname);   // '/users'
console.log(url.search);     // '?page=2&limit=10'

// Query parameters
const params = url.searchParams;
console.log(params.get('page'));    // '2'
console.log(params.get('limit'));   // '10'
params.append('sort', 'name');
params.delete('page');
console.log(url.toString());        // URL modificato

📊 Console avanzata

// Logging standard
console.log('Info');
console.error('Errore');
console.warn('Avviso');

// Tabelle
console.table([
    { nome: 'Mario', eta: 30 },
    { nome: 'Luigi', eta: 28 }
]);

// Timing
console.time('operazione');
// ... codice ...
console.timeEnd('operazione');  // operazione: 1.234ms

// Grouping
console.group('Gruppo 1');
console.log('Item 1');
console.log('Item 2');
console.groupEnd();

// Assert
console.assert(1 === 2, 'Questo non dovrebbe accadere!');

// Trace
console.trace('Stack trace completo');

🔒 TextEncoder / TextDecoder

// Converti stringa in bytes (UTF-8)
const encoder = new TextEncoder();
const bytes = encoder.encode('Hello 世界');
console.log(bytes);  // Uint8Array

// Converti bytes in stringa
const decoder = new TextDecoder();
const text = decoder.decode(bytes);
console.log(text);   // 'Hello 世界'

💡 Best practices

  • ✅ Usa process.env per configurazioni, mai hardcoded
  • ✅ Gestisci uncaughtException per evitare crash improvvisi
  • ✅ Usa Buffer.alloc() invece di allocUnsafe() per sicurezza
  • ✅ Pulisci sempre timer con clearTimeout/clearInterval
  • ✅ Usa console.time() per misurare performance
