📚 Riepilogo Lezione 1: Fondamenti di Architettura Web

🔄 Client-Server

Abbiamo imparato come funziona la comunicazione tra client (browser) e server attraverso richieste HTTP.

🏢 Architetture

Differenza tra architetture monolitiche (tutto in un blocco) e microservizi (componenti separati).

📱 Single Page Application

Le SPA caricano una sola volta e aggiornano il contenuto dinamicamente senza ricaricare la pagina.

🌐 Protocollo HTTP

Il linguaggio che browser e server usano per comunicare: GET, POST, PUT, DELETE.

🔑 Concetti chiave della Lezione 1

Concetto Cosa ricordare Perché è importante
REST API Interfacce standardizzate per comunicare tra sistemi Base per qualsiasi applicazione web moderna
JSON Formato per scambiare dati strutturati Linguaggio universale tra frontend e backend
JWT Token per autenticare utenti in modo sicuro Gestione sessioni nelle applicazioni moderne
CORS Meccanismo di sicurezza tra domini diversi Evita che siti malevoli rubino dati

La Lezione 1 è come imparare le regole del traffico stradale: hai capito i segnali (HTTP), le precedenze (sicurezza), e come funziona la comunicazione tra veicoli (client-server).

🚀 Riepilogo Lezione 2: Architetture Avanzate

⏱️ Promises & Async

Gestione del codice asincrono: Promise, async/await e combinatori come Promise.all().

⚙️ V8 & Event Loop

Come Node.js esegue JavaScript: motore V8, event loop e gestione migliaia di connessioni simultanee.

🌐 API REST

Progettazione e implementazione di API RESTful con Node.js ed Express.

🔗 Middleware

Funzioni che processano richieste in sequenza: autenticazione, logging, parsing dati.

🔑 Concetti chiave della Lezione 2

Concetto Cosa ricordare Quando usarlo
async/await Sintassi per scrivere codice asincrono come se fosse sincrono Sempre, quando lavori con operazioni asincrone
Promise.all() Esegue più Promise in parallelo Quando hai operazioni indipendenti da velocizzare
Event Loop Il "direttore d'orchestra" che gestisce l'asincronia Per capire come ottimizzare le performance
Middleware Funzioni che processano req/res in catena Autenticazione, validazione, logging

📖 Glossario rapido dei termini che userem o

Modulo
File JavaScript che esporta funzioni/oggetti riutilizzabili in altre parti del progetto
Package
Libreria o modulo scaricabile da NPM che aggiunge funzionalità al progetto
Dipendenza
Package esterno di cui il tuo progetto ha bisogno per funzionare
Stream
Flusso di dati processati "a pezzi" invece che tutti insieme (utile per file grandi)
Buffer
Area di memoria temporanea per gestire dati binari (immagini, video, ecc.)
Process
Oggetto globale che rappresenta il processo Node.js in esecuzione
